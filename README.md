# Hairday Template

O **Hairday Template** é um projeto front-end desenvolvido por [Pedro Augusto](https://github.com/pedro-augussto), utilizando tecnologias modernas como JavaScript, HTML, CSS e Webpack. Este template serve como base para projetos web, oferecendo uma estrutura organizada e pronta para desenvolvimento.

## 🛠 Tecnologias Utilizadas

- **JavaScript**
- **HTML5**
- **CSS3**
- **Webpack**

## 📁 Estrutura do Projeto

 ```bash

Hairday-Template/
├── dist/
├── src/
│   ├── assets/
│   └── styles/
├── index.html
├── package.json
├── webpack.config.js
└── server.json

```


- `dist/`: Arquivos de build gerados pelo Webpack.
- `src/`: Código-fonte do projeto, incluindo assets e estilos.
- `index.html`: Página principal do projeto.
- `package.json`: Gerenciamento de dependências e scripts.
- `webpack.config.js`: Configuração do Webpack.
- `server.json`: Configurações do servidor de desenvolvimento.

## 🚀 Como Utilizar

1. Clone o repositório:

   ```bash
   git clone https://github.com/pedro-augussto/Hairday-Template.git
   ```
   
   ```bash
   npm install
   npm start
   http://localhost:3000
   ```
   

📦 Scripts Disponíveis

npm start: Inicia o servidor de desenvolvimento.

npm run build: Gera os arquivos de produção na pasta dist/.
